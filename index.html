Rule 30 Pyramid

10,000 cells, one rule, and no way to predict the next row. Each cell is an agent you can mint once, Alive or Dead, and every agent comes with 1,000 $R30.

Testnet only. The app and both contracts run on Ethereum Sepolia. Nothing is live on mainnet yet.

Open the app (testnet) Read the source on GitHub

How it works

  1. Pick a cell of the pyramid and mint it for 0.009 ETH. It stays yours as a unique agent, Alive or Dead.
  2. Receive 1,000 $R30 with every agent minted. The maximum supply is 10,000,000.
  3. Once all 10,000 agents are minted, the market opens. Holders swap $R30 for ETH directly with each other, with a 3% fee on sales.

Why Rule 30

Each cell looks only at its left, centre and right neighbours, yet the pattern it draws is so irregular that Wolfram Mathematica has used its centre column as a random number generator since 1988. The same pattern appears on the shell of the Conus textile.

That is the whole rule. For each of the 8 possible neighbourhoods, the cell below turns red (Alive) or stays dark (Dead). Read the bottom line as a binary number, 00011110, and you get 30.
