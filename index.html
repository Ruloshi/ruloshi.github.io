Rule 30 Pyramid

An experimental on-chain project: a pyramid of 10,000 cells generated by the Rule 30 cellular automaton, where each cell is an agent that can be minted once (ERC-20 token $R30).

Status: testnet only (Ethereum Sepolia). Not yet launched on mainnet.
